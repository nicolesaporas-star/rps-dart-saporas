## Description
A console-based two-player Rock, Paper, Scissors game developed in Dart.

The program allows two players to:
- Enter their names
- Choose rock, paper, or scissors
- Hide Player 1's move before Player 2 enters their move
- Determine the winner of each round
- Track the current score
- Play multiple rounds
- Display the final score and overall winner

## How to Run

Make sure Dart is installed on your computer.

Open the terminal in the project folder and run:
